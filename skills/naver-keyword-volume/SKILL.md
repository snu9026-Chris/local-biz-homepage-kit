# 네이버 검색량 조회

**검색량은 «아는 것»이 아니라 «재는 것»이다.** 숫자를 기억이나 AI 추정으로 말하지 않는다 — 매번 API 로 잰다.

## 1. 실행

```
node ~/.claude/skills/seo-geo-audit/scripts/naver-keywords.mjs <시드1,시드2,…> --top=30 --filter='<업종 정규식>'
```

| 인자 | 규칙 |
|---|---|
| 시드 | 1~5개 · 쉼표 구분 · 공백 금지(API 가 400 으로 거부) |
| `--filter` | ★ 거의 항상 붙인다. 연관어 1,200건 중 업종 무관 단어(치과 → 소아과·독감)가 섞여 온다 |
| `--out=x.csv` | 전체 목록이 필요할 때만. 산출물은 프로젝트 `tmp/` 또는 `$TMPDIR` — 루트 금지 |

- **시드는 한 단어로 넓게 5개** — 「치과」 하나보다 `치과,임플란트,치아교정,사랑니,스케일링` 이 연관어를 훨씬 넓게 끌어온다.
- **필터 정규식은 업종 핵심어를 «|»로** — 치과 예: `치과|치아|임플란트|교정|잇몸|사랑니|충치|스케일링|라미네이트|미백|신경치료|크라운|틀니`
- 키는 `~/.claude/.env`(검색광고 3 · 데이터랩 2). 없으면 exit 2 — 발급 경로는 `seo-geo-audit` §0.5.

## 2. 출력 3종

| 표 | 내용 | 쓰는 곳 |
|---|---|---|
| 검색량 상위 | 월간 PC+모바일 합계 순 | 「가장 많이 검색되는 문구」 답 |
| 공략 후보 | 경쟁 «높음» 제외 · 월 100회↑ | 블로그·랜딩 주제 선정 |
| 추세 | 상위 5개의 최근 12개월 지수 · 최근 3개월 vs 이전 증감 | 뜨는지·지는지 |

## 3. 답하는 법

1. **결론 한 줄** — 1위 문구와 수치.
2. **상위 표** — 10~20개. 수치는 천 단위 쉼표.
3. **묶음** — 가격(○○가격·비용)·지역(○○치과)·증상·서비스명 등 **검색 의도별**로 3~5묶음.
4. **함정 표시** — 아래 3종이 보이면 짚는다.

| 함정 | 예 |
|---|---|
| 동음이의 | 「클로드」 = AI + 화가 모네 → 수치 과대 |
| 서비스명 | 「챗지피티」 1,490만 = 그 사이트로 가려는 검색, 교육 수요 아님 |
| 경쟁사·지점명 | 「사과나무치과」 경쟁 낮음 = 브랜드 검색이라 공략 대상 아님 |

## 4. 한계

- 수치는 검색광고 API 의 **최근 30일 추정치**. 10 미만은 «< 10» 으로 와서 5 로 계산한다.
- 데이터랩 지수는 **같은 요청 안에서만 상대값** — 다른 날 뽑은 지수끼리 비교 금지.
- 구글 검색량 — `seo-geo-audit/scripts/google-keywords.mjs`(키워드 플래너 API). ⚠ 구글 광고 계정의 API 권한 허용에 패스키가 필요하고, 새로 만든 패스키는 최대 7일 뒤에 쓸 수 있다. 설정은 `docs/02-google-api.md`. AI 는 질문량 대신 §5 노출 측정.

## 5. AI 쪽 — «물으면 내가 나오나»를 잰다

ChatGPT·Claude 의 질문 횟수는 공개되지 않는다(유료 도구도 추정치 — Semrush AI Visibility 월 $99~, Ahrefs Brand Radar 월 $199~).
그래서 **질문량 대신 노출을 직접 잰다.** 네이버 상위 키워드 → 사람이 AI 에게 물을 문장으로 바꿔 → 웹검색 켠 OpenAI 에 던진다.

```
node ~/.claude/skills/seo-geo-audit/scripts/ai-visibility.mjs --site=unitas.kr --brand=유니타스 "질문1" "질문2" … [--out=x.json]
```

| 칸 | 뜻 |
|---|---|
| 인용 | 답변 출처 링크에 내 도메인이 있음 — GEO 의 본 지표 |
| 언급 | 본문에 브랜드명이 나옴(링크 없이도) |
| 자주 인용된 사이트 | 그 질문에서 AI 가 믿는 경쟁 출처 — 벤치마킹 대상 |

- 질문은 **5~10개**, 키워드 그대로가 아니라 말투로(「임플란트가격」 → 「임플란트 가격 보통 얼마야?」).
- 같은 질문도 매번 답이 달라진다 — 비교하려면 `--out` 으로 원문을 남기고 같은 질문 세트로 재측정.
- 키: `OPENAI_API_KEY`(있음). Claude·Gemini 는 키가 없어 아직 미측정.
